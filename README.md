## 为什么同一个名字的 EB 套餐，价格差出一截

这是很多人翻资料时最懵的地方：有人写 `LAX.EB.TINY` 是 $9.99/月，有人写 $10.90，还有人写 $14.90。三个数字都不算错，因为**DMIT 在同一个 EB 产品线下并行跑着不同硬件平台**：AS3（AMD EPYC 7003）、AN4（EPYC 9004）、AN5（EPYC 9005）。同一档配置落在不同平台上，价格自然不同，越新的平台越贵。

大致规律是同档套餐在 AN5 平台比 AS3 贵 25%–35%，例如 TINY 三个平台分别约 $10.90 / $12.90 / $14.90，STARTER 约 $34.90 / $38.90 / $43.9 这个量级。

所以比价时别只盯「EB.TINY 多少钱」，要看清楚是哪个平台的。买之前确认两件事：**你要的是价格最低还是性能最新**。跑数据库、高并发这类对单核性能敏感的场景，AN5 的溢价有道理；纯粹做代理、建站、跑脚本，AS3 完全够，省下来的钱够多买几个月。

## EB 和 Pro、T1 到底怎么选

这三条线经常被放在一起比，其实定位很清楚：

- **Pro（CN2 GIA）**：三网回程全走 CN2 GIA，国内访问延迟和稳定性最好，代价是价格最高、流量最少。对延迟敏感的业务（实时交互、需要稳定低延迟的远程办公）优先考虑。
- **EB（CMIN2 + 9929）**：中国方向同样做了优化，但只对联通、移动更友好，电信去程绕行。同配置下流量给得比 Pro 多，价格低一档。主用移动或联通网络、预算有限但不想牺牲太多质量，EB 就是那个平衡点。
- **T1（国际线路）**：不做中国优化，价格最低，年付 $36.9 起。适合面向海外用户、或者你自己有中转方案的情况。如果你的主要场景是「国内直连访问快」，T1 会让你失望。

判断逻辑很朴素：**你的宽带是电信，优先 Pro；是联通或移动，EB 性价比更高；用户本来就在海外，T1 就够了。**

## 账户金返还是怎么回事

活动期间 DMIT 常搭配「账户金返还」，规则容易看错，这里拆开说：

- 返还是**按实付金额**算的，不是按原价。所以「20% 折扣 + 10% 返现」的实际总优惠约等于原价的 28%，不是 30%。
- 返还是**分期到账**的。年付分成 12 个月每月结算一次，季付就在 3 个月内分 3 次。
- 返还**只在第一个计费周期**。以年付为例，第 13 个月续费起就没有返现了，但循环折扣还在。
- 返还到账户的钱可以抵扣后续续费账单，也能买额外 IP、快照这类附加服务，没有过期限制。

很多人以为返现是一次性到账，结果买了年付看到账上没多钱，以为被坑了。其实是分月发的。

## 几个高频问题

**优惠码提示无效怎么办？**
先确认三件事：码是不是针对你选的这条产品线（洛杉矶 EB 的码对香港无效）；付款周期符不符合要求（不少码明确排除月付）；你选的机型是不是特价/限量款。三条都确认过还是无效，说明这个码对你已经失效了，别浪费时间。

**特价机型能用优惠码吗？**
基本不能。WEE、CORONA、FONTANA 这类限量特价的定位就是「已经打过折了」，活动规则里通常明确写着「不含特价产品」。反过来说，如果你抢到了 $39.9/年的 WEE，也不存在「还能再省一点」这种选项。

**优惠码可以叠加吗？**
不行，一单只能用一个。所以别去想「先用 10% 再用 20%」，不存在这种操作。挑适用于你这条产品线的最大力度那个就行。

**续费还打折吗？**
活动类优惠码给的是循环折扣，续费同价继续打，这点比一次性优惠码实在。但账户金返还只限首期，续费时就没有了。
